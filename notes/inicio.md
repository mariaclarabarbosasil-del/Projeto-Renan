# Comece por aqui

Este é um **segundo cérebro**: um conjunto de notas curtas ligadas entre si, em que o valor não está em nenhuma nota isolada, mas nas ligações entre elas.

O ponto de partida é o [[MOC — Mapa do Cérebro]], o mapa de conteúdo que organiza tudo. Se preferir navegar por ligações, comece por [[Segundo Cérebro]] e siga os `[[wikilinks]]` no final de cada nota.

## Como usar

- **Buscar** (`⌕` no topo) filtra notas por título, tag ou texto.
- **Grafo** mostra a estrutura inteira: nós são notas, linhas são wikilinks. Clique num nó para abrir.
- **Ligado por** no fim de cada nota mostra o que aponta para ela — a parte mais útil do sistema.

## Como crescer

1. Capture primeiro, organize depois: veja [[Captura de Informação]].
2. Escreva uma nota por ideia: [[Notas Atômicas]].
3. Ligue com `[[ ]]` sempre que uma ideia encostar em outra: [[Wikilinks]].
4. Reveja sem pressa: [[Revisão Espaçada]].

> Uma nota que não se liga a nada é um arquivo. Uma nota ligada a cinco é um pensamento.

Veja também [[Ferramentas]] para saber como adicionar notas novas e o que é o [[Projeto Renan]].
