# Escrita para Pensar

Escrever não é registrar um pensamento já pronto — é o processo que o produz. Enquanto a ideia está só na cabeça, ela parece completa; no papel, as lacunas aparecem.

## O sinal de que funcionou

Você começa a nota achando A e termina defendendo B. Se nada mudou, você transcreveu, não pensou.

## Técnica

1. **Uma frase por ideia.** Ver [[Notas Atômicas]].
2. **Explique como para um leigo** — inclusive os termos que você usa no automático.
3. **Escreva a objeção mais forte** antes de concluir. Se não houver objeção, o tema não foi explorado.
4. **Termine com uma pergunta aberta.** É o gancho para a próxima nota.

## Por que notas curtas ajudam

Textos longos escondem confusão atrás de transições. Uma nota de cinco frases não tem onde se esconder.

## Efeito no sistema

Cada nota escrita com clareza gera links melhores — você sabe exatamente o que está ligando. O [[Grafos de Conhecimento|grafo]] fica mais preciso, e o [[MOC — Mapa do Cérebro|MOC]] mais fácil de curar.

É a etapa "criar" do ciclo de [[Captura de Informação]] → ligação → escrita.
