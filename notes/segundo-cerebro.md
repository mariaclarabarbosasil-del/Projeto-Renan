# Segundo Cérebro

Um segundo cérebro é um sistema externo e confiável para guardar aquilo que você não quer (ou não consegue) manter na cabeça: ideias, referências, decisões, aprendizados.

A ideia central é simples: **a memória de trabalho é pequena; o espaço de armazenamento pode ser infinito.** Tirar informação da cabeça libera atenção para pensar, em vez de lembrar.

## Três trabalhos diferentes

| Trabalho | Pergunta | Ferramenta mental |
| --- | --- | --- |
| Capturar | "onde guardo isso agora?" | [[Captura de Informação]] |
| Conectar | "com o que isso se parece?" | [[Wikilinks]] |
| Criar | "o que emerge disso?" | [[Escrita para Pensar]] |

## O que diferencia de uma pasta de arquivos

Uma pasta guarda documentos para consulta futura. Um segundo cérebro guarda **ideias ligadas** — e é a ligação que gera insight. É a diferença entre um arquivo morto e um [[Grafos de Conhecimento|grafo]].

Por isso a unidade de trabalho não é o documento: é a [[Notas Atômicas|nota atômica]]. E o método clássico por trás disso tem nome: [[Zettelkasten]].

## Erros comuns

- **Colecionar em vez de pensar.** Salvar 500 artigos não é conhecimento.
- **Organizar demais.** Pastas profundas viram labirinto. Prefira ligações e um [[MOC — Mapa do Cérebro|MOC]].
- **Escrever para o outro.** Escreva para o seu "eu" de daqui a seis meses, que não lembra de nada.

> O segundo cérebro só funciona quando é mais fácil consultá-lo do que tentar lembrar.
