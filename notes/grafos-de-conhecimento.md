# Grafos de Conhecimento

Um grafo é a forma natural de visualizar um sistema de notas: cada nota é um **nó**, cada [[Wikilinks|wikilink]] é uma **aresta**. O que se vê não é o conteúdo, e sim a *topologia* do pensamento.

## O que o grafo revela

- **Nós grandes** são hubs: notas muito citadas. Costumam ser conceitos fundadores — como [[Segundo Cérebro]] e [[Wikilinks]].
- **Nós isolados** são ilhas: ideias sem conexão. Ou estão incompletas, ou não pertencem ao vault.
- **Cachos densos** são temas maduros, onde as notas já conversam entre si.
- **Pontes** entre cachos são as notas mais valiosas: conectam domínios diferentes.

## O que ele esconde

Uma aresta diz que existe ligação, não que ela é boa. Grafo bonito não é sinônimo de conhecimento profundo — e um grafo esparso pode ser só um vault jovem. A leitura honesta exige abrir as notas.

## Ligado por e densidade

| Métrica | O que mede | Sinal de alerta |
| --- | --- | --- |
| Grau | quantas ligações | 0 = ilha |
| Retro-ligações | quem aponta para cá | 0 = beco sem saída |
| Densidade | arestas / nós possíveis | alta demais = redundância |

## Como usar na prática

Abra o modo **Grafo** no topo. Clique nos hubs para revisitar os fundamentos, procure os nós isolados e escreva uma ligação para cada um. É a mesma manutenção periódica descrita em [[Revisão Espaçada]], aplicada à estrutura em vez do conteúdo.

O grafo é o retrato do [[MOC — Mapa do Cérebro|mapa]] — só que honesto.
