# Revisao Semanal

Mapa: [[MOC Revisoes]]

Reserve cerca de 20 minutos e crie um registro com [[Modelo de Revisao]].

## Esclarecer

- [ ] Processar a [[Caixa de Entrada]].
- [ ] Identificar pendências e definir próximas ações.

## Atualizar

- [ ] Revisar cada projeto em [[MOC Projetos]].
- [ ] Conferir as responsabilidades em [[MOC Areas]].
- [ ] Encerrar ou pausar o que perdeu prioridade.
- [ ] Levar os itens inativos para [[Arquivo]].

## Conectar

- [ ] Revisar as novas notas em [[MOC Conhecimento]].
- [ ] Conectar notas úteis aos mapas e explicar relações relevantes.
- [ ] Abrir o grafo e verificar se alguma nota ficou sem contexto.

## Escolher

- [ ] Selecionar até três resultados prioritários para a próxima semana.
- [ ] Registrar uma melhoria para simplificar o sistema.
